DAA ASYMPTOTIC NOTATIONS SUBMISSION PACKAGE

Files:
- report.pdf: printable report (if included in this package)
- report.tex: editable LaTeX source
- references.bib: bibliography file
- main.py: animation source code
- requirements.txt: Python dependencies
- growth_rates_animation.gif: animated demonstration
- figures/: plot and four keyframe screenshots for the report

To run:
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: pip install -r requirements.txt
4. Run: python main.py

IMPORTANT:
Check the student details on the title page, especially SAP ID, batch, submission date,
and faculty name, before submitting. The SAP ID and faculty details were read from
the supplied screenshots and should be verified. The report includes an AI-use declaration;
edit it honestly if your actual use differs.
